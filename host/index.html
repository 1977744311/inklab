相机来源

mock
切到电脑摄像头会立即申请浏览器权限，但不读取或保存照片；拒绝后可点「授权 / 重试」。 真正取景只发生在应用由你的按键/点击交互调用 takePhoto 时。命令行 E2E 始终固定为模拟图片。

蓝牙来源

mock
idle
模拟模式内置一个心率设备；应用先扫描、连接并订阅后，才能发通知。 业务设备可用 __inklab.bluetooth.replaceDevices(...) 配置；通知 trace 可直接导入 十六进制帧，并显示已发送帧数、循环次数与失败状态。电脑模式先由应用发起搜索；若引擎桥跨过了浏览器的 用户手势窗口，“选择真实设备”会使用同一组服务过滤条件打开系统选择器，并让原扫描继续。 命令行 E2E 始终固定为模拟蓝牙。

网络

online
断网 = 拦截器 block + 连通性事件 offline；宿主自己取源码的那条 fetch 不受影响。 「挡外域」默认开：应用里硬编码的线上域名（启动预取这类）会在你按任何按钮之前就打出去， 默认挡下既是隐私边界也是跑测的稳定前提；要放行单个域名用 __inklab.caps.net.allowExternal('域名')。

传感器 / IMU

baseline
trace 在下一次传感器 start 时生效；JSON 可直接写样本数组，或写 {sensor, speed, samples}。深蹲示例只验证流程/算法，不冒充真机信号。 腕表 IMU 仍走上方模拟蓝牙的 playNotificationTrace。故障是粘的，需手动清除。
